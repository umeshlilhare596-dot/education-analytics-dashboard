Education Analytics

Project Overview

Education Analytics is a data analytics project that analyzes students' academic performance using Python. It helps understand students' marks, attendance, and results through data analysis and visualizations.

Objectives

- Analyze students' academic performance.
- Calculate total and average marks.
- Study student attendance.
- Identify students' results and performance.
- Present insights through an interactive dashboard.

Features

- Student performance analysis
- Subject-wise average marks
- Attendance visualization
- Result filtering
- Interactive dashboard
- Student performance table
- Top-performing students

Technologies Used

- Python
- Pandas
- Streamlit
- Jupyter Notebook
- GitHub

Project Files

- "app.py" – Streamlit dashboard application
- "requirements.txt" – Required Python libraries
- "Education_Analytics.ipynb" – Jupyter Notebook for data analysis
- "README.md" – Project documentation

How to Run the Project

1. Clone or download this repository.

2. Install the required libraries:
   
   "pip install -r requirements.txt"

3. Run the dashboard:
   
   "streamlit run app.py"
